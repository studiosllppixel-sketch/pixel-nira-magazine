# Pixel Studios × Nira Editorial

A fresh, independent fashion-magazine website concept for Pixel Studios × Nira Editorial.

## Current phase

This repository contains the first responsive homepage concept:
- Premium editorial visual direction with warm paper, ink, and serif typography
- Fashion, beauty, culture, and studio sections
- Mobile-friendly navigation and responsive layouts
- Separate Pixel Studios and Nira Editorial social links

## Run locally

Open `index.html` in a browser, or use any static development server.

## Planned next phases

1. Refine the homepage against the approved visual concept.
2. Build the visual editorial CMS/editor: canvas selection, drag positioning, crop/focal point, typography, layout presets, desktop/mobile variants, drafts and undo.
3. Add authenticated admin access and connect Supabase for content, media metadata, and publication versions.
4. Match editor preview and public rendering using the same page schema and components.
5. Connect a separate Vercel project after review and explicit deployment approval.

## Important

This is a front-end concept. Newsletter signup is a placeholder and does not collect or store email addresses. No Supabase credentials, private keys, or production data are included. The previous `pixel` repository is separate and is not modified by this project.
